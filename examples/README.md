# Примеры сохранённых расчётов

Сгенерированы `python -m scripts.examples` (алгоритм 0.2.0, 2026-09-19T09:23:02Z). Каждый ZIP — та же выгрузка, что кнопка «Сохранить (ZIP)» в консоли: `report.html`, `brief.html`, `run.json` (запрос, момент отсечки, оценки по механизмам, рекомендация, доказательства со ссылками на сырые файлы `raw_id`, версия алгоритма и хэши настроек), `series.csv`, `windows.csv`, `intervals.csv`, для прогноза из прошлого — `verification.json` (сверка с фактом).
