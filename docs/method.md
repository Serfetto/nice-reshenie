# Метод оценки (алгоритм v0.1)

Как сервис превращает данные в рекомендацию по окну ВКД. Параметры — [config/thresholds.yaml](../config/thresholds.yaml);
значения черновые и помечены как подлежащие уточнению.

## 1. Время и срез данных

Все расчёты идут через срез «что было известно на момент T» ([services/assessment/slice.py](../services/assessment/slice.py)).
Запись видна, если её время публикации не позже отсечки источника:

| Данные | Время публикации |
|---|---|
| Алерты и предупреждения SWPC | `Issue Time` в тексте сообщения |
| 3-дневный прогноз, RSGA | `:Issued:` в файле |
| Элементы орбит (Space-Track) | `CREATION_DATE` |
| Протоны GOES, Kp (живые) | конец интервала измерения (оценка) |
| Протоны GOES (архив NCEI L2), Kp GFZ | восстановлено как конец интервала; помечено «реконструкция» |

Орбитальные элементы: среди наборов, опубликованных до T, берётся набор с самой поздней эпохой.
Режим разбора использует весь архив и помечается как реконструкция. Отключение или заморозка источника
действуют только на конкретный расчёт.

## 2. Орбита

SGP4 по TLE → TEME → ITRF (поворот на GMST) → WGS84. Сетка 30 с.
Магнитное поле IGRF-14: модуль |B| (ЮАА) и центрированный диполь (геомагнитная широта λm).

## 3. Механизм 1 — радиационная обстановка на траектории

**Слой 1, измерение.** Интегральный поток протонов GOES ≥10, 30, 50, 100, 500 МэВ (pfu, геостационар).
Архив 2024 г. восстановлен интегрированием дифференциальных каналов SGPS L2 (максимум двух апертур); для
события 08.06.2024 это воспроизводит оперативные данные SWPC: пик 996 pfu против 1030 pfu в 08:00, превышение
10 pfu в 02:55 и 1 pfu ≥100 МэВ в 02:25 — минута в минуту.

**Слой 2, условие на траектории.** Жёсткость обрезания Штёрмера в точке МКС

Rc = 14.9 · cos⁴(λ_eff) / r² ГВ,  λ_eff = |λm| + a·Kp,  a = 1°/Kp (черновое)

Буря (высокий Kp) сдвигает границу проникновения частиц к экватору — поэтому Kp не отдельный риск, а модификатор
Rc (нет двойного счёта бури и протонного события). Энергия обрезания E_cut(Rc) — из релятивистской связи
жёсткости и энергии протона. Поток, проникающий к МКС, оценивается по спектру GOES:

J_iss = J(>E_cut)  — лог-лог интерполяция по порогам, выше 500 МэВ — экстраполяция наклоном 100–500 МэВ.

ЮАА: |B| на высоте МКС < 21 000 нТл (~8 проходов, ~75 мин в сутки).

**Слой 3, последствие для ВКД (класс).**

| Условие | Класс | Основание |
|---|---|---|
| ≥10 МэВ на геостационаре ≥ 1000 pfu (S3+) | критический | шкала NOAA S: при S3 рекомендовано избегать ВКД |
| J_iss ≥ 10 pfu | критический | частицы события проникают к МКС (черновой порог) |
| J_iss ≥ 1 pfu | нежелательный | частичное проникновение (порог = уровень алерта SWPC ≥100 МэВ) |
| ≥10 МэВ ≥ 10 pfu (S1+), МКС под защитой | нежелательный | событие идёт |
| проход ЮАА | нежелательный | захваченные протоны, ожидаемый фон — минимизируется |
| иначе | приемлемый | |
| нет измерения и прогноза | нет данных | никогда не превращается в «приемлемо» |

J_iss — показатель обстановки, а не доза.

**После момента отсечки** обстановка снаружи берётся по приоритету:

1. **Собственный прогноз на 6 ч** (от последнего свежего измерения, спектральная форма сохраняется):
   спад — экспонента, подогнанная по последним 3 ч (не быстрее 0.7 ln/ч); нарастание — рост с тем же темпом,
   ограниченный ×10; иначе — сохранение. Уверенность: средняя до 3 ч, низкая 3–6 ч.
2. **Предупреждения SWPC** (WARPX1 ≥10 МэВ >10 pfu, WARPC0 ≥100 МэВ >1 pfu) с учётом продлений и отмен:
   поток не ниже порога предупреждения на время действия. Внешний прогноз, уверенность средняя.
3. **Суточная вероятность** (3-дневный прогноз S1, RSGA «Proton»): ≥50% — нежелательно, иначе приемлемо;
   уверенность низкая. Если событие идёт, за горизонтом прогноза — нежелательно.
4. Иначе — нет данных. Если измерения устарели (старше 30 мин на момент отсечки), прогноз не строится.

Kp: наблюдение → прогноз SWPC → сохранение 6 ч → консервативно Kp = 5 (с понижением уверенности).

## 4. Механизм 2 — сближения с отслеживаемыми объектами

Каталог Space-Track: объекты, чей перигей < 460 км и апогей > 380 км (полоса высот МКС), последние элементы,
опубликованные до T, эпоха не старше 3 суток. Все объекты распространяются SGP4 на сетке МКС; вокруг локальных
минимумов расстояния — уточнение с шагом 0.5 с. Объекты, в среднем ближе 10 км к МКС на всём интервале
(пристыкованные корабли), исключаются.

Сближение с проходом через зону контроля (±2 км по радиусу, ±25 км вдоль и поперёк орбиты; значения по открытым
материалам NASA, проверить) — **критический фактор** на интервале TCA ± 10 мин, по бинарному принципу
(позиция постановщика на QA-сессии). Вероятность попадания фрагмента в космонавта не оценивается.
Каталог недоступен или устарел (старше суток) — нет данных.

## 5. Окна и правило выбора

Окна заданной длительности с шагом 15 мин по периоду поиска (+ плановое окно). Для каждого окна и механизма —
минуты по классам, уверенность, для радиации — оценка потока за окно Σ J_iss·Δt (pfu·мин) и минуты без
количественной оценки. Запас на задержку — через сколько минут после окончания начинается первый критический фактор.

| Правило | Содержание |
|---|---|
| R1 | критический фактор в окне → «не рекомендуется» |
| R2 | интервалы без данных → «требует проверки» |
| R3 | остальные: меньше минут нежелательных условий по механизмам (Парето, затем приоритет радиация > сближения), затем меньше минут без количественной оценки, затем меньше потока за окно |
| R4 | несравнимые окна (одно лучше по одному механизму, другое — по другому): приоритет механизмов, компромисс выводится явно |
| R5 | при равенстве — больший запас на задержку |
| R6 | разница в пределах допуска (5 мин, 20% потока) — «равнозначно» |
| R7 | нет окна без критических факторов → «нет подходящего окна»; все остальные с пропусками → «недостаточно оснований» |

Механизмы не складываются: хорошие данные по одному не компенсируют критический фактор или отсутствие данных
по другому. Рекомендация с низкой уверенностью помечается как предварительная, с подсказкой, когда пересчитать
(ближайшие выпуски прогнозов SWPC, вход окна в горизонт собственного прогноза).

## 6. Проверка

Сверка replay: тот же запрос пересчитывается по всему архиву; сравниваются классы по минутам после T
(ЮАА исключена) и статус рекомендованного окна. Эксперимент — `python -m scripts.experiments`,
результаты — [experiments.md](experiments.md).
