## Почему так (выбор и ранжирование)

- **Радиация**: GOES — единственный непрерывный ряд потока протонов по энергиям; алерты SWPC — официальный факт
  начала/конца событий и готовые предупреждения (внешний прогноз). Kp нужен только для геометрии проникновения
  частиц, поэтому не является отдельным риском.
- **Сближения**: постановщик рекомендовал взять объекты на орбите МКС и считать сближение бинарным фактором.
  Собственный отбор по каталогу Space-Track работает одинаково для «сейчас» и для 2024 г. (история `gp_history`
  с датой публикации) — в отличие от SOCRATES, у которого нет архива.
- **Метеорные потоки**: единственный открытый датированный прогноз для мелких частиц, которые не видны поштучно;
  опубликован заранее — строгий replay; почасовой — различает окна вместе с экранированием Землёй.
- **Приоритет внутри механизма 1** после отсечки: собственный прогноз по свежему измерению → предупреждения SWPC →
  суточные вероятности → «нет данных».

## Сознательно не используется

| Кандидат | Причина |
|---|---|
| Шкала R (радионарушения) | другое явление — КВ-радиосвязь, не условие ВКД |
| Освещённость | условие работ, не опасность (рассчитывается и отдаётся в рядах `sunlit`) |
| DONKI GST, Kp с других сайтов | повтор того же измерения — не независимое подтверждение |
| SOCRATES | нет архива; порог 5 км по дальности уже зоны контроля МКС вдоль орбиты; заменён собственным отбором |
| NASA OEM | пригоден для истории орбиты, но Space-Track закрывает и историю, и текущую орбиту одной цепочкой |
| Электроны >2 МэВ на геостационаре | не вошли в охват: связь потока на геостационаре с дозой на коже при ВКД в высоких широтах требует модели внешнего пояса; кандидат на развитие |
| Солнечный ветер ACE/DSCOVR | даёт 30–60 мин до бури; развитие (адрес SWPC сменился) |
| DONKI вспышки | развитие: вспышка — предвестник протонов (08.06.2024: M9.7 за 1.5 ч до начала события) |
